# 本機開發環境

這台電腦是 Apple M5 Max，128 GB 統一記憶體，macOS 27.2，套件管理用 Homebrew（/opt/homebrew）。

## zsh 與 Powerlevel10k

zsh 5.9 是 macOS 內建的預設 shell。主題用 Homebrew 安裝 powerlevel10k，字型安裝 font-meslo-lg-nerd-font。
iTerm2 的字型選單找不到 MesloLGS 時，原因是字型檔放在 ~/Library/Fonts 但 macOS 沒有登錄。
解法是用 Swift 呼叫 CoreText 的 CTFontManagerRegisterFontsForURL，把 MesloLGS NF 註冊成永久的使用者字型。

## Docker Desktop

選 Docker Desktop 而不選 Apple container，因為 Docker Compose 有官方支援，而且和 Docker 工具完全相容。
安裝指令是 brew install --cask docker-desktop，過程需要 sudo 密碼，必須在 iTerm2 裡執行。
Client 和 Engine 都是 29.9.2，Engine 跑在 linux/arm64，Docker Compose 是 v5.6.1。
x86 映像檔可以用 --platform linux/amd64 以模擬方式執行。

## 雙螢幕排列

接了兩台 1920x1080 外接螢幕。主螢幕是 VA27EHF（100Hz），副螢幕是 PA278CFRV（60Hz）。
用 displayplacer 調整排列，origin 是螢幕左上角座標，主螢幕固定在 (0,0)。
副螢幕 origin 設 (1920,0) 表示排在主螢幕右邊，設 (-1920,0) 表示排在左邊。
